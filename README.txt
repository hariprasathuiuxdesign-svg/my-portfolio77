V. Hari Prasath - UI/UX portfolio

Files
  index.html        the page structure and all the content
  style.css         all the styling
  script.js         all the interactions (hero cursor effect, stage and water, charts, tabs)
  assets/img/       the images used in the page
  assets/data.js    a few images the scripts need (kept inside a script so the effects work offline)

How to open
  Double-click index.html. The page loads its fonts (Anton, Sora, Space Grotesk, JetBrains Mono, Pixelify Sans)
  from Google Fonts, so open it with an internet connection to see them exactly as designed.

Keep the folder together. index.html, style.css, script.js and the assets folder must stay side by side.
